# 前端工程师 → Java / Go 全栈 → AI 全栈：12 个月无脑学习计划

> **适用对象：** 已经具备 Vue / TypeScript 实际开发经验的前端工程师  
> **学习目标：** 12 个月内形成「前端 + Java 后端 + 数据库 + Redis + MQ + Docker + Go + AI 应用开发」的完整能力  
> **学习时间：** 工作日每天 2 小时，周六/周日每天 8 小时，共约 **18 小时/周**  
> **核心原则：** 不追求把所有知识学完，而是按照「学 → 写 → 做项目 → 复盘」推进

# 一、最终能力目标

12 个月以后，你的技术栈建议形成：

```text
                    AI
                     │
          ┌──────────┼──────────┐
          │          │          │
         LLM        RAG       Agent
          │          │          │
          └──────────┼──────────┘
                     │
                  全栈应用
                     │
        ┌────────────┼────────────┐
        │            │            │
      Vue/TS       Java          Go
        │         Spring Boot     │
        │            │            │
        └────────────┼────────────┘
                     │
              MySQL / Redis / MQ
                     │
                Linux / Docker
```

最终应该能够：

- 独立设计前后端 API
- 使用 Spring Boot 开发后端
- 使用 MySQL 完成数据库设计
- 使用 Redis 做缓存、Session、分布式能力
- 使用 MQ 完成异步任务
- 使用 Docker 部署完整项目
- 能读懂并修改 Linux 环境下的服务
- 使用 Go 开发简单 Web 服务
- 接入 LLM API
- 实现 RAG
- 实现 Tool Calling / Agent
- 理解 MCP
- 使用 Codex / Claude Code 等 AI Coding 工具完成工程任务
- 独立完成一个 AI 全栈项目

# 二十四、资料使用优先级

遇到一个知识点时，严格按照：

```text
① 主视频课程
       ↓
② 官方文档
       ↓
③ 自己写代码
       ↓
④ AI 提问
       ↓
⑤ 项目中使用
```

不要：

```text
B站看一个
 ↓
知乎看一个
 ↓
博客看一个
 ↓
公众号看一个
 ↓
GitHub 再找一个
 ↓
最后什么都没学会
```

**这一份计划的核心就是：只跟一条主线走。**

# 结语

这条路线不要求你一年后成为：

> Java 专家 + Go 专家 + AI 专家。

真正的目标是：

> **你仍然是一个强前端工程师，但已经能够独立完成后端、数据库、部署和 AI 能力接入。**

这会比单纯增加一门语言更有价值。

**执行优先级永远是：**

```text
项目 > 理解 > 编码 > 视频时长 > 教程数量
```

只要按照每周 18 小时持续执行，一年后你应该已经完成多个完整项目，并具备把 AI、前端和后端真正组合起来的能力。
